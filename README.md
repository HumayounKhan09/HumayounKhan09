## 🚀 Projects

### 🧾 Mortgage Transcript Analyzer
**Deterministic transcript parser for mortgage servicing workflows.**
Built to help teams triage calls faster by extracting structured signals from messy conversations.

**What it does:**
- Intent classification (payment, hardship, escrow inquiry, etc.)
- Escalation trigger detection (legal threats, abusive language, supervisor requests)
- Entity extraction (amounts, dates, phone numbers, loan numbers)
- Risk scoring (low / medium / high)

**Results:**
- Processed 12 transcripts in 15ms vs. an estimated 2 minutes per transcript manually
- 244 tests (133 unit, 91 integration) across each engine and end-to-end pipeline validation

### 🌐 Concurrent File Transfer Server
**UDP file transfer system implementing Go-Back-N and Stop-and-Wait protocols from scratch.**
Handles the full transmission cycle from handshake to teardown.

**Results:**
- Go-Back-N outperformed Stop-and-Wait by 36x on large file transfers under high packet loss
- Averaged 1.3s vs. 47s on the same workload

### ❌⭕ Adversarial AI Benchmarking Agent
**Multi-strategy AI system with automated round-robin benchmarking across game board sizes.**
Built to compare classical game AI against a live Gemini opponent.

**My contributions:**
- Implemented Expectiminimax and Minimax with Alpha-Beta Pruning
- Integrated Gemini as a live opponent via prompt engineering
- Built an automated evaluation harness using NumPy to log win/draw rates
